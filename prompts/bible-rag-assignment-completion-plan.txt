# PRIMARY PRIORITIES (Assignment-Critical)

These items have the highest importance.

## Priority 1 — Standardized answer() Interface

Ensure strict compliance with assignment API:

```python
def answer(question: str) -> dict:
    return {
        "answer": str,
        "sources": list[str],
        "retrieved_chunks": list[dict],
        "debug": dict
    }
```

Retrieved chunks must contain:
- chunk_id
- text
- display_text
- score
- dense_score
- lexical_score
- metadata

Remove unstable/internal-only fields from public responses.

---

## Priority 2 — Evaluation Pipeline

Implement:

```text
eval/
├── gold_set.jsonl
├── run_eval.py
├── metrics.py
├── manual_eval_template.csv
└── results/
```

Evaluation must be reproducible and runnable with:

```bash
python eval/run_eval.py
```

---

## Priority 3 — Retrieval Metrics

Implement:
- Hit@1
- Hit@3
- Hit@5
- Recall@5
- MRR

Evaluation flow:
1. run retrieval
2. compare retrieved chunk_ids against expected chunk_ids
3. compute metrics
4. save structured JSON results
5. generate readable summaries

Store:
```text
eval/results/retrieval_eval.json
```

Also generate Markdown summaries.

---

## Priority 4 — Answer Evaluation

Implement:
- Exact Match
- Semantic Similarity
- Citation Presence
- Hallucination Detection

Flag:
- unsupported answers
- irrelevant citations
- missing citations

Optional:
- GPT-as-judge evaluation

Manual review support is REQUIRED.

---

## Priority 5 — Manual Evaluation

Generate:

```text
eval/manual_eval_template.csv
```

Columns:

- human_score
- citation_quality
- notes

## Priority 6 — Ablation Experiments

Implement automated experiment runner.

Required comparisons:
- dense_only vs lexical_only vs hybrid
- single_verse vs sliding_window
- top_k: 3 vs 5 vs 10

Store:
```text
eval/results/ablation_results.json
```

Generate:
- Markdown tables
- CSV exports
- charts-ready outputs

Automatically classify common failure types:
